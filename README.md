## Домашнее задание
### Вариант: 22
### Задание:
#### Составить программу, которая интерпретирует степени 10 в соответствующие приставки вида «пико», «нано» ... «тера».
### Алгоритм:
#### 1. Инициализация: 
#### – Объявление переменной 'x' для хранения введенной степени пользователя 
#### 2. Ввод необходимых данных: 
#### – Программа выполняет приглашение пользователя к вводу степени словами: 'Введите степень'
#### – Программа производит считавшие информации введенной пользователем с помощью scanf() и хранит его в x
#### 3. Вывод форматированного основания:
#### – Программа выполняет печать числа '"10^x: "', где вместо x подставляет число введенное пользователем 
#### 4. Выбор с помощью switch:
#### – Программа сравнивает введенное пользователем значение x со степенями в программе 
#### – При x = 12 программа печатает 'тера (Т)' и останавливается благодаря команде break 
#### – При x = 9 программа печатает 'гига (Г)' и останавливается благодаря команде break
#### – При x = 6 программа печатает 'мега (М)' и останавливается благодаря команде break
#### – При x = 3 программа печатает 'кило (К)' и останавливается благодаря команде break
#### – При x = 2 программа печатает 'гекто (Г)' и останавливается благодаря команде break
#### – При x = 1 программа печатает 'дека (Д)' и останавливается благодаря команде break
#### – При x = 0 программа печатает 'единица' и останавливается благодаря команде break
#### – При x = -1 программа печатает 'деци (Д)' и останавливается благодаря команде break
#### – При x = -2 программа печатает 'санти (С)' и останавливается благодаря команде break
#### – При x = -3 программа печатает 'милли (М)' и останавливается благодаря команде break
#### – При x = -6 программа печатает 'микро (Мк)' и останавливается благодаря команде break
#### – При x = -9 программа печатает 'нано (Н)' и останавливается благодаря команде break
#### – При x = -12 программа печатает 'пико (П)' и останавливается благодаря команде break
#### – Если программа обнаруживает, что пользователь ввел степень, которой нет в программе, то применяется default и выводит сообщение: 'неизвестна или не входит в диапазон пико...тера' 
#### 5. Завершение: 
#### – Если все условия программой были выполнены верно, то она успешно завершается с возвратом кода '0'
